# React Native 0.85 Line Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bare React Native 0.85 builds: a `0.85` row in `SUPPORTED_LINES` (0.85.x from 0.85.0, verified 0.85.0 and 0.85.3), proved on a fresh 0.85.0 template through rn-xtool's own download, adapter, vendored scripts and G4, with the project's CLI at 20.1.0 and at 20.0.0, and with the work app's reanimated 4.3.x + worklets 0.8.x. The drift watch checks 0.85 daily and stops exploring it weekly. The row is merged only after the owner's device pass.

**Architecture:** No new mechanism. The row is data: the version gate, `supportedRnList()`, `doctor`'s `versions` line, `unsupportedReason`, the daily drift targets and the drill ids all read `SUPPORTED_LINES`. The scripts mode comes from the installed scripts' shape (0.85 ships none → `vendored`). The artifacts go through the 0.86 adapter unchanged (`ADAPTER_VERSION` stays 1). Hermes comes from the project's `hermes-compiler` through the vendored downloader. The only code that may name a version is the owner-ruled reanimated fallback hint (Task 6b), and only if the generic fix fails.

**Tech Stack:** TypeScript (Node 22.12+, ESM), vitest, `tsc --noEmit` as lint, the vendored RN 0.88.0 scripts (`vendor/rn-spm`), patch-package, xtool 1.24.0, Swift 6.4 with the Darwin SDK (proof only), `@react-native-community/cli` 20.1.0 and 20.0.0 (proof only).

**Spec:** `docs/design/specs/2026-11-04-rn-085-line-design.md` (approved, commit 8f3cbf0). Its failure-walk rulings are binding, with the owner's rulings on its open questions below. Findings from the preflight that would change the spec are listed for the owner at the end; this plan does not edit the spec.
